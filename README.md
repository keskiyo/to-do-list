# My-todo-list

Сайт: https://keskiyo.github.io/to-do-list

## Возможности

- Несколько списков задач.
- Добавление, удаление и переименование списков.
- Добавление, редактирование, удаление и завершение задач.
- Приоритеты задач: низкий, средний, высокий.
- Срок выполнения задачи.
- Заметки к задачам.
- Отметка важных задач.
- Поиск, фильтры и сортировка задач.

## Стек

- React
- TypeScript
- Vite
- Tailwind CSS

## Запуск

```bash
npm install
npm run dev
```

Локально приложение открывается по адресу:

```text
http://127.0.0.1:5175/to-do-list/
```
